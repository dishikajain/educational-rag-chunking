# A Comparative Study of Document Chunking Strategies in Retrieval-Augmented Generation for Educational Question Answering

**Research Question:** Does preserving pedagogically coherent learning units during document chunking improve retrieval effectiveness and answer quality in Retrieval-Augmented Generation systems for educational question answering?

**Note:** This is a research project. Data and formal results are not committed to git.
